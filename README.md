Enterprise Endpoint Security & SOC Lab

Designed and implemented a simulated enterprise endpoint-security environment using Wazuh, Windows Event Logging, Windows Firewall, and role-based access controls. The project demonstrates endpoint monitoring, security alert investigation, firewall rule management, risk assessment, and incident response.
